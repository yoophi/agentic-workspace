# Feature Specification: 창 글꼴 크기 조정

**Feature Branch**: `035-adjust-font-size`

**Created**: 2026-07-31

**Status**: Draft

**Input**: User description: "창의 폰트 크기 조정 기능을 추가하고 싶습니다. cmd + , cmd - 로 폰트크기를 줄일 수 있도록 하고, 설정에서도 폰트를 -2 -1 0 1 2 단계로 (slider 이용하여) 크기 조정할 수 있도록 합니다"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 단축키로 글꼴 크기 조정 (Priority: P1)

Agentic Workbench에서 작업 중인 사용자는 현재 맥락을 벗어나지 않고 `Cmd++` 또는 `Cmd+-`를 눌러 앱의 글꼴을 한 단계씩 키우거나 줄인다.

**Why this priority**: 작은 글씨를 읽기 어렵거나 한 화면에서 더 많은 정보를 보고 싶은 사용자가 작업 흐름을 끊지 않고 즉시 가독성을 조정하는 핵심 기능이다.

**Independent Test**: 기본 단계에서 각 단축키를 한 번씩 실행해 표시 단계가 `1`, 다시 `0`으로 바뀌고 열린 창의 텍스트 크기가 즉시 달라지는지 확인할 수 있다.

**Acceptance Scenarios**:

1. **Given** 글꼴 크기가 `0` 단계이고 Agentic Workbench 창이 활성화된 상태, **When** 사용자가 `Cmd++`를 누르면, **Then** 글꼴 크기가 `1` 단계가 되고 열린 모든 Agentic Workbench 창의 텍스트가 즉시 커진다.
2. **Given** 글꼴 크기가 `0` 단계이고 Agentic Workbench 창이 활성화된 상태, **When** 사용자가 `Cmd+-`를 누르면, **Then** 글꼴 크기가 `-1` 단계가 되고 열린 모든 Agentic Workbench 창의 텍스트가 즉시 작아진다.
3. **Given** 사용자가 텍스트를 입력하거나 작업 세션을 보고 있는 상태, **When** 글꼴 크기 단축키를 누르면, **Then** 입력 내용, 선택 항목, 스크롤 가능한 작업 내용과 실행 중인 세션은 유지된다.

---

### User Story 2 - 설정에서 원하는 단계 선택 (Priority: P2)

사용자는 설정 창에서 슬라이더를 움직여 `-2`, `-1`, `0`, `1`, `2` 중 원하는 글꼴 크기 단계를 직접 선택하고 현재 선택값을 확인한다.

**Why this priority**: 단축키를 기억하지 못하는 사용자에게 발견 가능한 조정 방법을 제공하고, 원하는 단계로 여러 번 누르지 않고 이동할 수 있게 한다.

**Independent Test**: 설정 창의 슬라이더에서 각 다섯 단계를 차례로 선택해 선택값 표시, 열린 창의 글꼴 변화, 저장된 값이 모두 일치하는지 확인할 수 있다.

**Acceptance Scenarios**:

1. **Given** 사용자가 설정 창을 연 상태, **When** 글꼴 크기 슬라이더를 `2` 단계로 이동하면, **Then** 슬라이더는 `2`를 현재 값으로 표시하고 열린 모든 Agentic Workbench 창의 텍스트가 즉시 해당 단계로 커진다.
2. **Given** 글꼴 크기가 `-2` 단계인 상태, **When** 사용자가 설정 창을 닫았다가 다시 열면, **Then** 슬라이더는 저장된 `-2` 단계를 표시한다.
3. **Given** 사용자가 키보드만 사용하는 상태, **When** 글꼴 크기 슬라이더에 초점을 두고 값을 조정하면, **Then** 다섯 단계 사이를 이동하고 현재 값을 인식할 수 있다.

---

### User Story 3 - 선택한 크기를 다음 실행에도 유지 (Priority: P3)

사용자는 단축키나 설정에서 선택한 글꼴 크기가 모든 Agentic Workbench 창에 일관되게 적용되고 앱을 다시 실행한 뒤에도 유지되기를 기대한다.

**Why this priority**: 접근성 환경설정을 매번 다시 조정해야 하는 불편을 없애고 여러 창 사이에서 일관된 가독성을 보장한다.

**Independent Test**: 한 창에서 `1` 단계를 선택한 뒤 다른 창과 재실행한 앱에서 모두 `1` 단계가 적용되고 설정 슬라이더도 `1`을 표시하는지 확인할 수 있다.

**Acceptance Scenarios**:

1. **Given** Agentic Workbench 창이 둘 이상 열려 있는 상태, **When** 한 창에서 글꼴 크기를 변경하면, **Then** 모든 열린 Agentic Workbench 창이 같은 단계를 표시한다.
2. **Given** 사용자가 `1` 단계를 선택하고 앱을 종료한 상태, **When** 앱을 다시 실행하면, **Then** 첫 창부터 `1` 단계가 적용되고 설정에도 같은 값이 표시된다.
3. **Given** 단축키로 단계를 변경한 상태, **When** 사용자가 설정 창을 열면, **Then** 슬라이더는 단축키로 변경된 현재 단계를 표시한다.

### Edge Cases

- 현재 값이 `2`일 때 `Cmd++`를 누르거나 `-2`일 때 `Cmd+-`를 눌러도 값은 허용 범위를 벗어나지 않으며 오류나 예상치 못한 화면 변화가 발생하지 않는다.
- 저장된 값이 없으면 `0` 단계를 사용한다.
- 저장된 값이 손상되었거나 다섯 단계 밖의 값이면 안전하게 `0` 단계로 복구하고 앱 사용을 계속할 수 있어야 한다.
- 글꼴 크기를 바꾼 뒤 긴 제목, 표, 코드, 타임라인, 버튼 레이블이 커지거나 작아져도 핵심 작업과 조작 요소에 접근할 수 있어야 한다.
- 설정 창과 메인 작업 창 중 어느 창에서 단축키를 실행해도 같은 앱 전체 값이 적용되어야 한다.
- 기존 `Cmd+,` 설정 열기 단축키와 글꼴 크기 단축키는 서로의 동작을 가로채지 않아야 한다.
- 운영체제나 키보드 배열상 `+` 입력에 보조 키가 필요한 경우에도 사용자가 일반적으로 인식하는 `Cmd++` 조합으로 동작해야 한다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템은 Agentic Workbench의 글꼴 크기를 `-2`, `-1`, `0`, `1`, `2`의 정확히 다섯 단계로 제공해야 한다.
- **FR-002**: 시스템은 처음 사용하거나 유효한 저장값이 없을 때 `0` 단계를 기본값으로 사용해야 한다.
- **FR-003**: 사용자는 `Cmd++`로 현재 글꼴 크기를 한 단계 키울 수 있어야 한다.
- **FR-004**: 사용자는 `Cmd+-`로 현재 글꼴 크기를 한 단계 줄일 수 있어야 한다.
- **FR-005**: 시스템은 `2`보다 크게 또는 `-2`보다 작게 조정하려는 입력에서 현재 경계값을 유지해야 한다.
- **FR-006**: 설정 창은 다섯 개의 이산 단계만 선택할 수 있는 글꼴 크기 슬라이더와 현재 선택값을 제공해야 한다.
- **FR-007**: 글꼴 크기는 단축키 또는 설정 슬라이더에서 변경되는 즉시 열려 있는 모든 Agentic Workbench 창에 동일하게 반영되어야 한다.
- **FR-008**: 시스템은 마지막으로 선택한 글꼴 크기 단계를 저장하고 다음 앱 실행의 첫 창부터 복원해야 한다.
- **FR-009**: 단축키와 설정 슬라이더는 하나의 동일한 현재 값을 읽고 변경해야 하며, 어느 경로에서 변경해도 다른 경로에 최신 값이 표시되어야 한다.
- **FR-010**: 글꼴 크기 변경은 입력 내용, 현재 세션, 선택 상태, 실행 중인 작업을 초기화하거나 중단하지 않아야 한다.
- **FR-011**: 시스템은 저장된 값이 유효한 다섯 단계 중 하나가 아니면 `0` 단계로 복구해야 한다.
- **FR-012**: 글꼴 크기 변경은 텍스트의 가독성을 조정하되 이미지와 아이콘 자체의 배율을 글꼴 단계 값으로 변경하지 않아야 한다.
- **FR-013**: 설정 슬라이더는 포인터와 키보드 조작을 모두 지원하고 현재 값과 조정 가능한 범위를 보조 기술에 전달해야 한다.
- **FR-014**: 기존 `Cmd+,` 설정 열기 동작은 글꼴 크기 단축키 추가 후에도 동일하게 유지되어야 한다.

### Key Entities

- **글꼴 크기 환경설정**: 앱 전체에 적용되는 현재 글꼴 크기 단계. 허용값은 `-2`, `-1`, `0`, `1`, `2`이며 기본값은 `0`이다.
- **글꼴 크기 조정 동작**: 단축키 또는 설정 슬라이더에서 환경설정 값을 변경하는 사용자 동작. 모든 진입점은 동일한 값을 대상으로 한다.

## Constitution Alignment *(mandatory)*

- **Monorepo boundary**: `apps/agentic-workbench` 단독 범위다. 다른 앱에 같은 요구가 확인되지 않았으므로 이번 기능에서 교차 앱 공유를 도입하지 않는다.
- **Frontend layering**: 앱 전체 환경설정의 제공과 창 간 동기화는 `app`, 설정 화면은 `pages`, 단축키와 슬라이더 조정 동작은 `features`, 글꼴 크기 모델과 환경설정 접근은 `entities`, 범용 표현 요소는 기존 `components/ui` 또는 `shared` 책임으로 구분한다.
- **Backend boundary**: 영속 저장이 앱 경계를 통과하는 경우 입력 경계는 허용 단계 검증과 위임만 담당하고, 환경설정 규칙은 애플리케이션 책임, 저장 세부사항은 인프라 책임으로 분리한다. 순수 값 모델과 저장 추상화는 외부 저장 기술에 의존하지 않아야 한다.
- **Shared core vs UI**: Agentic Workbench 전용 사용자 경험으로 유지한다. 둘 이상의 앱이 동일한 단계 모델을 실제로 소비하게 되기 전에는 공유 패키지나 공유 UI로 승격하지 않는다.
- **Persistence and safety**: 기존 앱 환경설정 저장 위치와 권한 범위를 재사용하며, 글꼴 크기 변경은 프로젝트 파일, 작업 디렉터리, 세션 소유권, 실행 권한을 변경하지 않는다.
- **Documentation and Storybook**: 설정 화면의 다섯 단계와 키보드 조작 상태를 페이지 또는 재사용 컴포넌트 스토리에 등록한다. 사용자용 설정 문서가 있다면 `docs/*.md`의 한국어 문서를 갱신한다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 사용자는 활성 Agentic Workbench 창에서 단축키를 누른 뒤 1초 이내에 글꼴 크기 변화를 확인할 수 있다.
- **SC-002**: 사용자는 설정 창에서 두 번 이하의 조작으로 다섯 단계 중 원하는 글꼴 크기를 선택하고 현재 값을 확인할 수 있다.
- **SC-003**: 단축키, 설정 슬라이더, 여러 열린 창, 앱 재실행에서 확인한 글꼴 크기 단계가 100% 동일하다.
- **SC-004**: 경계값에서 각 방향 단축키를 5회 연속 눌러도 값은 `-2`~`2` 범위를 벗어나지 않고 작업 상태 손실이 발생하지 않는다.
- **SC-005**: 대표적인 메인 화면과 설정 화면을 다섯 단계 모두에서 검증했을 때 핵심 텍스트와 조작 요소의 100%가 읽고 사용할 수 있는 상태를 유지한다.
- **SC-006**: 키보드 사용자 테스트에서 참여자의 90% 이상이 별도 도움 없이 설정 슬라이더의 현재 값을 확인하고 원하는 단계로 변경할 수 있다.

## Assumptions

- 대상은 기존 별도 설정 창과 `Cmd+,` 설정 열기 동작을 제공하는 Agentic Workbench다.
- `Cmd++`는 글꼴 확대, `Cmd+-`는 글꼴 축소를 뜻한다. 사용자 설명의 "줄일 수 있도록"은 양방향 크기 조정을 요청한 것으로 해석한다.
- 글꼴 크기 단계는 특정 창이나 프로젝트별 값이 아니라 사용자에게 적용되는 앱 전체 환경설정이다.
- 각 단계의 구체적인 크기 차이와 글꼴별 비율은 시각적 가독성과 레이아웃 검증을 거쳐 계획 단계에서 정한다.
- 이번 범위는 텍스트 크기 조정이며 전체 화면 확대/축소, 이미지 확대, 아이콘 확대, 사용자 지정 글꼴 선택, `Cmd+0` 초기화 단축키는 포함하지 않는다.
- macOS 단축키가 직접 범위이며 다른 운영체제용 대응 단축키는 이번 명세에 포함하지 않는다.
