- 기존 `v2026.8.1-rc.1` 태그와 GitHub prerelease는 RC 이력으로 유지한다.
- RC의 prerelease 표시만 해제하지 않는다. 정식 릴리스는 별도 버전 `2026.8.1`과 annotated tag `v2026.8.1`로 게시한다.
- RC 이후 앱 동작에 영향을 주는 수정이 포함되면 바로 Stable로 승격하지 않고 `2026.8.1-rc.2`를 먼저 배포해 검증한다.
- 정식 릴리스 빌드는 검증된 커밋과 태그에서 재현 가능해야 한다.
