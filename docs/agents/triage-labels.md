# Triage 라벨

| 표준 역할 | 실제 라벨 | 의미 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 유지보수자의 검토가 필요함 |
| `needs-info` | `needs-info` | 제보자의 추가 정보를 기다림 |
| `ready-for-agent` | `ready-for-agent` | 충분히 구체화되어 에이전트가 처리할 수 있음 |
| `ready-for-human` | `ready-for-human` | 사람의 구현 또는 판단이 필요함 |
| `wontfix` | `wontfix` | 처리하지 않기로 결정함 |

스킬이 표준 역할을 언급하면 이 표의 실제 라벨을 사용한다.
