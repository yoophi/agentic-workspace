관측 시각: 2026-08-12 16:42 KST  
방법: 각 프로젝트의 `main` 브랜치 README와 저장소 내 지원 표만 확인했다. 여기서 **지원**은 프로젝트가 명시한 코딩 에이전트 CLI/앱의 연결·실행·관찰 지원을 뜻하며, 지원 엔진이 모두 같은 제어·이력 수집 수준이라는 뜻은 아니다.

## 요약

- **Claude Code 전용**: Claude Task Viewer, Claude Code Agent Farm, Claude Code Monitor.
- **Claude Code와 Codex 양쪽을 명시 지원**: CCC, Agent Orchestrator, Orca, Claude Squad, Claude Code Agent Monitor, abtop, Open Island.
- **Codex 외 다수 엔진을 한 표면에서 다루려는 도구**: CCC(8개 전용 adapter), Agent Orchestrator(26개 worker harness), Orca(모든 CLI agent), Open Island(10개), Claude Squad(임의 local program).
- “다중 엔진” 비교 시에는 **실행만 가능한지**, **상태/이력까지 읽는지**, **후속 지시·권한 승인까지 가능한지**를 분리해 판단해야 한다.
